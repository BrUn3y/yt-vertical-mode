# Changelog

## 1.1.0 — 2026-11-13

- Translate the extension, settings, popup, guides, and project documentation into English.
- Redesign the popup and player settings with a powder-blue frame, warm paper surfaces, large typography, and fine rules.
- Add a responsive GitHub Pages website with an interactive framing demo, Chrome and Dia installation steps, usage instructions, update guidance, and FAQs.
- Share the settings interface and framing geometry between the actual extension and the website preview.
- Package versioned and stable release ZIPs with SHA-256 checksums.
- Add automated syntax, asset, version, shared UI, geometry, manifest, and packaging checks in GitHub Actions.

## 1.0.0 — Local prototype

- Add Vertical mode beside YouTube's fullscreen control.
- Reframe video without stretching, with crop and horizontal framing controls.
- Preserve native player controls and save framing settings locally.
- Support fullscreen, window mode, Escape, and Alt + Shift + V.
- Handle YouTube navigation, metadata updates, and nested controls.
